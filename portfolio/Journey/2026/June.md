# Migration, Not Patching

Stopped trying to patch Firebase and started moving house to Supabase.

## Company Development
- **Firebase to Supabase Migration**: Started a complete migration from Firebase to Supabase. A lot of work, learning Postgres, REST APIs, SQL and rethinking data access from the ground up.
- **Diffspe Experiment**: Toyed around with a new project, Diffspe. Three years ago and backwards, it would have been a great build and a game changer in the software development lifecycle. With AI now, not so much, so I shelved it.

## Personal Development
- **Student Again**: Going from NoSQL comfort to Postgres discipline was uncomfortable in a good way. Relearning fundamentals mid-project kept me honest.

## The Lessons
- **Sometimes Migrate, Don't Patch**: Patching would have preserved the same cost structure. Migration was harder but addressed the root problem.
- **Timing Decides Value**: Diffspe was a solid idea at the wrong time. A great build launched late is still late.
